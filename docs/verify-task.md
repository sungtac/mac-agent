# verify-task.js

`workflows/verify-task.js` — a Claude Code Workflow script. Given a completed task (`task`, `result`, optional `persona`/`cwd`/`maxRounds`/`historyFile`), it first runs a preflight check (Codex/Antigravity login status — fails fast with guidance to `setup.sh` if either is missing), then independently scores the result with both Codex and Antigravity/Gemini against a shared 100-point rubric (pass at 85+, with a dealbreaker rule for critical categories), revises on failure, and loops until it passes or `maxRounds` is hit. Full rubric lives in the script's `RUBRIC` constant.

- **Grades real evidence, not just a self-report.** If `cwd` is given, `gatherVerificationContext()` collects real `git log`/`git diff HEAD`/`git show HEAD` output up front and hands the *same* evidence text to both graders — they're told to weigh it over the agent's own summary and flag any mismatch. Without `cwd`, graders are told explicitly that unverifiable claims ("tests passed") should be scored conservatively rather than taken at face value. An earlier version let each grader run its own shell commands to "verify" — that's what originally caused Gemini/agy to fail under headless invocation (see below) and is why evidence-gathering was centralized into one step done by the orchestrating agent instead.
- **Scoring calls go through a deterministic dispatcher, not ad-hoc LLM-constructed shell commands.** `workflows/lib/score-dispatch.sh <codex|agy> <prompt-file>` runs the actual CLI and extracts/validates the JSON verdict in code (brace-matching + `json.loads`, robust to both single-line and markdown-fenced multi-line output). The `agent()` calls only do: write the prompt to a temp file, run the dispatcher, return its stdout, delete the temp file — no shell string ever gets built by interpolating `task`/`result` text directly (that was a real shell-injection vector: `JSON.stringify(prompt)` spliced into a command string does *not* neutralize `$(...)`/backticks, since JSON-escaping isn't shell-escaping). On tool crash/timeout/unparseable output, the dispatcher emits a fixed, code-authored failure envelope (`dealbreaker: true`, scores all 0) — it never asks an LLM to "make up something schema-shaped," which used to let a failed grading run silently masquerade as a real score.
- **Why Gemini/agy needs pre-gathered evidence instead of exploring `cwd` itself:** `agy -p` (headless) auto-denies any tool call needing the "command" permission — it can't prompt for approval non-interactively, and there's no clean headless-approval flag analogous to Codex's `sandbox: read-only` + `approval: never`. (Don't try to force this with `--dangerously-skip-permissions` — Claude Code's own auto-mode classifier reliably flags that flag as a permission-escalation pattern and blocks the *outer* Bash call attempting it.) Since evidence is now gathered once up front and given to agy as plain text, agy never needs to execute anything itself, so the permission wall never comes up.
- **If `maxRounds` is exhausted without passing:** the script does NOT silently give up or silently accept — it returns `finalVerdict.needsUserDecision: true` with a `reason`. Workflow scripts can't call AskUserQuestion themselves, so **the calling agent is responsible for surfacing this to the user** (accept as-is / retry with higher maxRounds / manual fix) rather than treating a `needsUserDecision` result as done.
- **History logging:** every run appends one JSONL record (task excerpt, persona, round count, pass/fail, both final scores, UTC timestamp) to `historyFile` (default `~/.claude/verify-task-history.jsonl`), via an agent() call using Bash+Write (the script itself has no filesystem access).
- **Prerequisites on the machine running it:** Codex CLI (`codex`, logged in) and Antigravity CLI (`agy`, logged in) both on PATH — run `setup.sh` to check/install/fix. Both `verify-task.js` and `score-dispatch.sh` currently hardcode the Antigravity binary at `/Users/edge_ai/.local/bin/agy` and the dispatcher's own path at `/Users/edge_ai/mac-agent/...` — adjust these if installed elsewhere.
- Usage: `Workflow({scriptPath: "workflows/verify-task.js", args: {task, result, persona, cwd, maxRounds, historyFile}})`, or copy/symlink it into `~/.claude/workflows/` to invoke by `name: "verify-task"`.
