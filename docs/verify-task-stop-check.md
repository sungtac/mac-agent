# verify-task-stop-check.sh

`hooks/verify-task-stop-check.sh` — a Claude Code `Stop` hook. Registered in `~/.claude/settings.json` under `hooks.Stop`, it fires every time a session ends (including `/clear`, `/resume`, `/compact`). It's a **mechanical proxy, not real judgment**: it can't tell a good edit from a bad one. It counts `Edit`/`Write` tool calls (≥3) or risky `Bash` commands (git commit/push, brew/npm/pip install, plugin install, marketplace add, rm -rf, chmod +x) in the session transcript, and if any of that happened with no mention of `verify-task` anywhere in the transcript, it blocks the stop once (via `decision: "block"` + a reason fed back to the model) asking the agent to either run `verify-task` or tell the user why it's being skipped. It nags **at most once per session** (tracked via a marker file in `~/.claude/hooks-state/verify-task-nag/`) so a genuinely-trivial session can't get stuck in a loop.

- **Why code, not just memory:** relying on the agent to just remember to run `verify-task` was demonstrably forgotten in practice (see the HWPX plugin install task, 2026-07-24) — the user asked for this to be enforced mechanically instead so it can't be silently skipped.
- **Deliberately `command`, not `prompt`/`agent`:** Claude Code's `Stop` hooks actually do support `type: "prompt"` (routes to a quick Claude call) and `type: "agent"` (spawns a real subagent) — verified 2026-07-25, correcting an earlier wrong claim in this doc that `command` was the only option here. This hook stays `command` anyway: it's a cheap, fast, deterministic pre-filter that runs on *every* session end, and `prompt`/`agent` types would mean an LLM call on every single Stop event just to maybe decide "no verification needed" — not worth the latency/cost for what's meant to be a lightweight mechanical gate. So this hook is a blunt keyword/count heuristic on purpose, not genuine judgment — false positives (nagging on trivial sessions) and false negatives (missing substantive work that doesn't match the heuristic) are both possible, and both are considered an acceptable trade for staying cheap and instant.
- To port to another agent/machine: add the same `hooks.Stop` entry (command: `bash <path-to-this-repo>/hooks/verify-task-stop-check.sh`) to that machine's `~/.claude/settings.json`.
