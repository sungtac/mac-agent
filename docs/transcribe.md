# transcribe.sh (일정비서 — recording transcription)

`bin/transcribe.sh` — transcribes an audio file to text using local `whisper-cpp` (installed via `brew install whisper-cpp`; model: `whisper-models/ggml-large-v3-turbo-q5_0.bin`, 547MB, downloaded from the ggerganov/whisper.cpp Hugging Face repo). Fully offline, Metal-accelerated on this Mac's M4 GPU, multilingual with language auto-detection (verified accurate on synthesized Korean speech via `say -v Yuna`). Auto-converts non-native formats (m4a/aac from phone voice memos, etc.) to wav via `ffmpeg` first — whisper.cpp natively decodes wav/flac/mp3/ogg only. Usage: `bin/transcribe.sh <audio-file>` prints the clean transcript to stdout (all whisper.cpp diagnostics go to stderr, so stdout is directly usable).

- **Why this exists / how it's meant to be used:** built to unblock a "auto-organize shared recordings" use case. The user will share audio files two ways — drop a file in a folder and tell Claude the path, or attach it directly in a Claude Code chat — both of which happen *inside* a live session. Deliberately does **not** wire this into a new automated pipeline: since it's always used within a session, the existing `hooks/work-log-stop-check.sh` Stop hook already handles the "organize + log to Calendar" half automatically once a transcript/summary file gets written during that session — no new Stop hook or launchd job needed for this specific flow. A separate scenario (recordings landing in a folder via phone/recorder sync with **no** Claude Code session involved at all) was raised earlier and intentionally deferred — genuinely needs a periodic watcher, not built.
- **Output convention:** when writing up a transcribed recording (or any archived work material — documents too, not just recordings) into `업무아카이브`, always structure it as 요약 (summary) → 액션플랜 (checklist of concrete next steps grounded in the actual content) → 전체 원문/전사 (full source). Not just summary + raw content — see [[feedback_recording_action_plan]] memory for why.
- **Porting caveat:** hardcodes Apple Silicon Homebrew paths (`/opt/homebrew/bin/whisper-cli`, `/opt/homebrew/bin/ffmpeg`) — on an Intel Mac these would be under `/usr/local/bin` instead, update the script.
- To port to another agent/machine: `brew install whisper-cpp`, then download a model file from https://huggingface.co/ggerganov/whisper.cpp/tree/main into `whisper-models/` (same filename, or update `MODEL` in the script) — the model itself isn't checked into this git repo (547MB).
